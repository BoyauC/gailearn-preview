# CH3－查核行動指揮中心

國中版互動式教材原型。玩家以新進調查員的第一人稱視角進入指揮中心，透過角色對話與線索分類理解「不急著猜真假，先找可靠證據」。

## 目前範圍

- 平板橫向首頁（優先支援 4:3 與 16:10）
- 指揮中心序幕場景
- 可可、思思、小澄、歐匿角色立繪
- 姓名牌、資料化對話、打字效果與顯示全文
- 三個行動選項與局部分支後匯流
- 「神奇飲料傳言」三問調查室
- 點擊案件中的可疑位置，逐張取得調查線索
- 依「簡易查核小技巧」的三問：誰說的／何時發布／合不合理，完成判斷
- 每張線索再選擇可補足證據的下一步行動
- 左側固定小澄證據員／調查夥伴區，右側固定任務區
- 小澄即時追問、錯誤補救、行動紀錄與證據缺口統整
- 黃色警報及下一步查核說明
- 案件01結案後由歐匿通報新案件，明確區隔兩個情境
- 關卡二「全臺停課三天？」查核行動盤
- 固定先停止轉傳，中段查核行動可依情境自由排序
- 蒐集證據後才解鎖警報判斷與分享／不分享分流
- AI 答案、分享數與只看標題等證據不足回饋
- 可撤回上一項查核結果，再自由選擇其他行動
- 關卡三「查核工具選擇所」三件短案件
- 每案以四選二方式調度核心與輔助工具，免拖曳
- 使用臺灣事實查核中心、MyGoPen與165全民防騙網／防詐騙諮詢專線等具名工具
- 舊圖重用、政府補助網址與 AI 論文引用的工具配對及證據回饋
- 小澄對話框固定於立繪上方；工具可再次點選取消，答錯後會重設選項
- 綜合挑戰「熟人視訊緊急求助」：結束催促通話、改用可信管道查證並採取安全行動
- 以虛構人物局部馬賽克、訊號干擾與文字呈現視訊壓力，不製作擬真 Deepfake
- 通話中使用 `assets/images/video-caller-mosaic.png`；結束通話後切換為無視訊畫面
- 高風險匯款與個資選項提供安全攔截，不以失敗羞辱學生
- 鍵盤焦點、減少動態偏好與直向相容版面

尚未實作完整能力值、音效檔與進度儲存。音效開關目前只作為共用介面模板。

## 本機預覽

因為對話資料使用 `fetch()` 載入，請勿直接雙擊 `index.html`。在本資料夾啟動靜態 HTTP 伺服器：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

再開啟 `http://127.0.0.1:8000/`。

## GitHub Pages

所有資源均使用相對路徑，可部署至：

```text
https://<帳號>.github.io/<儲存庫>/CH3-fact-check-command-center/
```

在儲存庫的 **Settings → Pages**，選擇 **Deploy from a branch**、正式分支及 `/(root)`，不需修改外層檔案。

## 後續架構

後續關卡沿用 `screen → scene → dialogue/choice` 元件；案件、對話、選項與回饋放入 `data/`，程式只處理狀態、呈現及輸入。圖片、音效與圖示各自放在 `assets/` 對應子目錄。
