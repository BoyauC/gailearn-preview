# CH5｜打造我的全科 AI 學伴

國中版第五章互動式教材。玩家參加「全科 AI 學伴設計大賽」，在五天內完成 25 個設計決策，平衡專案進度與倫理風險，並面對延遲後果與七種結局。

## 本機預覽

本教材使用 `fetch()` 載入事件資料，需透過靜態 HTTP 伺服器預覽：

```powershell
npx --yes serve .
```

或使用任何能提供靜態檔案的本機伺服器。

## 結構

- `index.html`：畫面與無障礙結構
- `css/style.css`：AI 學伴設計實驗室主題及響應式版面
- `js/app.js`：五日流程、雙數值、徽章、旗標、存檔與結局
- `data/events.json`：由最新版 Obsidian 劇本產生的 25 個事件與 75 個選項
- `scripts/build-events.mjs`：從工作區劇本副本重新產生事件資料
- `assets/characters/`：角色圖像
- `assets/scenes/`：主持人、指導老師與評審橫式場景
- `assets/badges/`：五大倫理徽章正式圖像
- `assets/endings/`：A～G 七種結局的星芽圖像

## 操作與裝置

- 平板橫向優先，兼容桌面、平板直向與手機。
- 所有任務可用點擊或鍵盤操作，不需要拖曳。
- 每次開始新挑戰會隨機排列選項；同一次挑戰重新整理後會維持原順序。
- 支援減少動態、高對比、文字放大及本機進度保存。
