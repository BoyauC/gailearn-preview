# 地圖比例測試原型

> 2026-08-28：地圖世界改為固定 `1920 × 1080`（16:9）設計畫布，依可用視窗等比例縮放並置中。建築、人物、出生點、房門與碰撞座標因此共用同一比例基準；人物高度不再直接依瀏覽器 `vh` 計算。畫布外留白不接受點擊移動，避免平板與桌面不同比例造成座標偏移。

用途：在正式地圖美術與完整角色動畫製作前，驗證阿岳四向待機母檔於平板橫向、桌面及手機上的顯示比例與操作感。

> [!info] 第二次尺寸回復｜2026-08-27
> 實機確認正面移動時的 `1.38` 倍補償反而使人物放大，停止時縮回待機尺寸，因此已完整移除該補償；正面步行格與待機格現在共用相同 CSS 顯示高度。SIFT偵探房縮為上一版的90%，位置以原建築中心校正，房門與碰撞區同步更新。

> [!info] 正面四格步行原型｜2026-08-27

> [!info] 景深與方向動畫節奏｜2026-08-27
> GIF逐格確認正、背、側素材的可見輪廓仍有差異。正式四方向精靈完成前，地圖加入由上至下 `0.88 → 1.12` 的輕度景深比例：遠景人物較小、近景人物較大，腳底座標與碰撞點不變。正面四格維持每格140毫秒，背面180毫秒，左右方向放慢為200毫秒；左右正式影格後續須重製較小步幅版本。

> [!info] 景深幅度收斂｜2026-08-27
> 依 `0449.GIF` 逐格檢查，正面四格沒有明顯逐格尺寸跳動，但原先 `0.88 → 1.12` 的位置縮放在垂直移動時過於容易察覺。景深已收斂為由上至下 `0.92 → 1.08`，保留遠小近大的方向，同時降低人物像被持續拉伸的感受。

> [!info] 背面四格小步幅原型｜2026-08-27
> 新增 `walking-back-v4`：以背面待機母檔製作半個鞋長的小步幅姿勢，再鏡像為相反腳步，與待機格組成四格循環，每格160毫秒。兩張大跨步生成候選因步幅與背景不合格而未接入；新素材先使用透明PNG，實機確認後再轉WebP。

> [!failure] 背面v4撤回｜2026-08-27
> `0623.GIF` 逐格確認新版小步影格與待機格切換時鞋尖向外，鏡像後形成外八感，整體不如原版自然。原型已恢復 `normalized-v3` 的背面步行格與180毫秒節奏；`walking-back-v4` 僅保留作失敗紀錄，不再載入。

## 測試項目

- 固定 1024 × 1536 透明母檔以腳底中央定位。
- 點擊土地、鍵盤方向鍵／WASD、觸控方向按鈕三種移動方式。
- 房門互動支援鍵盤：進入觸發範圍後按 Enter 開啟確認視窗，再按 Enter 執行主要操作；Esc 返回地圖。Enter 只在房門或對話視窗情境生效，不影響 WASD、滑鼠及觸控。
- 依移動方向切換正、背、左、右素材。
- 移動時播放逐格獨立生成的單人跨步圖，停止時維持該方向待機單格。正面使用左右腳兩格與待機過渡，背、左、右先使用一格跨步與待機交替。
- 角色依地圖 Y 座標調整前後遮擋層級，但顯示尺寸固定，不套用近大遠小縮放。
- 四棟正式透明小型建築與左側廣場提供比例、遮擋及空間密度參考。
- 四棟建築具有測試碰撞區，角色不可直接穿越建築本體。
- 點擊建築會引導角色走到對應門前；接近房門後才顯示「進入挑戰」，避免移動途中誤觸。
- 「進入挑戰」提示改置於遊戲畫面中央，以遊戲式確認框呈現；四棟房屋向外拉開，中央保留提示框的視覺空間。
- 「逃離過濾氣泡」房依畫面標示移至左下方較低位置，對應碰撞區與房門目標點已同步下移。
- 確認進入只開啟原型說明視窗，不會跳轉房間或寫入進度。
- 支援四個正式 `entry` ID：先讀取參數、設定對應地圖標題，再將角色放到指定房門前稍遠處；玩家仍須自行移動並確認進入。
- 使用 `shared-core/progress-store.js` 驗證統一 localStorage 進度介面；房門視窗可模擬首次完成與回顧去重，重新整理後完成數仍保留。
- 支援 `?return={room_id}` 返回流程：角色在剛離開的房間出口附近出生，完成紀錄存在時只顯示一次授章提示；沒有完成紀錄時明確提示 `return` 不是通關證明。
- 房門確認後前往 `prototypes/room-roundtrip-test` 獨立測試頁，由房間頁寫入完成狀態再返回地圖；地圖頁不再直接模擬完成。
- 四房 ID、名稱、資料夾、房間標題與地圖入口標題改由 `shared-core/room-registry.js` 集中提供。
- 四種入口出生姿勢統一改為房門側邊的左／右側臉，面向房門；玩家向前走一小段即進入互動範圍，避免背面角色出生時遮住房間名稱。
- 下方滑桿可比較角色高度 15%～28%，預設值為 21%。

## 已確認決定｜2026-08-25

- 本階段先採用預設角色高度 `21%`，不以使用者端滑桿預覽結果作為定案依據。
- 已依主要企劃修正為左側小型廣場；無入口參數的測試出生點亦設於廣場附近，不再以地圖正中央作正式配置。
- SIFT 偵探房的水平位置已右移至「逃離過濾氣泡房」與「AI夥伴協作導演房」之間的中線附近，上下層次維持不變。
- 左側小型「中央廣場」統一更名為「廣場」，操作按鈕同步改為「回到廣場」。
- 正式場景採滿版地圖：紅框／遊戲視窗內皆屬可設計的地貌範圍，不使用中央橢圓綠島加外圍大片淺藍空白的構圖。原型已將草地延伸至整個地圖視窗；正式美術可再用花台、步道、沙地、休憩區與資料牆建立自然邊界。
- `21%` 是地圖比例原型的暫定基準；正式建築尺寸、碰撞區及平板實機整合完成後，仍可作小幅技術調整。
- 後續製作正式步行影格時，應維持人物相對比例一致，不因不同方向或動作任意改變角色高度。

## 界線

- 地貌與四棟建築已接入正式美術候選，但目前仍是比例與碰撞校準原型，不代表正式首頁完成。
- `map-layout.js` 的碰撞矩形、房門座標、接近距離及入口出生點是依 v6 比例建立的第一輪數值；必須完成四入口實際走動測試後才能升格為正式設定。
- 正式地圖與四棟建築造型確認後，必須依實際屋頂、牆面、房門、招牌及人物腳底位置重新繪製或校準碰撞範圍。
- 正式碰撞驗收須確認：角色不穿牆、不被屋頂錯誤阻擋、可順利走到門前、招牌不被遮住、對話框觸發距離合理，且平板點擊移動不會卡在建築邊角。
- 尚未加入房間實際跳轉、正式房內完成回傳、證書或 GA；localStorage 目前只供進度介面原型驗證。
- 四向母檔原始人物腳底高度略有差異；本原型先以圖片畫布底部作共同錨點，正式切格前仍須整理透明邊界與基準線。
- 正面步行來源第四格右下角含孤立雜點，原型刻意不載入該格，暫以 `1→2→3→2` 循環；正式素材定稿前需補製乾淨的第四格。
- 2026-08-25依操作錄影修正換格殘影：移除角色動態 `drop-shadow` 合成濾鏡，並持續保留及預解碼四向影格快取，避免移動時反覆解碼大型 WebP。
- 第二次檢查確認殘影來自橫向生成表的相鄰人物跨格重疊，部分分格同時含上一人的鞋或手。原型已停用整批 `walking-v1` 換格動畫，只載入乾淨四向單格；`walking-v1` 保留作失敗紀錄，不得當正式素材。正式步行必須逐格獨立生成、逐格驗證後才接入。
- 已建立 `walking-individual-v1` 作為替代：每張只有一名完整角色，輸出時清除 Alpha 低於 32 的生成光暈；原型目前以每格 180 毫秒播放，避免滑動感及跨格肢體殘片。
- 錄影確認換格已有步行感，但略有放大縮小。原型已改用 `walking-individual-v2`：逐方向以待機圖的可見高度、腳底 Y 座標及水平中心重新對齊，降低換格時的縮放跳動。
- 本原型不部署、不取代正式首頁。
