# 地圖後側與邊緣模組

## rear-boundary-density-preview-v1.webp

- 用途：確認後側圍牆、花台、樹木、座椅與燈具在四棟地圖中的密度及遮擋程度。
- 本圖是 1920 × 1080 全圖預覽，不是正式合成底圖，也不直接接入遊戲。
- 建築、人物、廣場與中央留白延續 v5 已確認比例。

### v1 配置

- 上緣以低矮暖灰圍牆與花台形成不連續邊界。
- 配置數棵中型、樹冠較疏的校園樹木，主要位於建築後方。
- 上方配置少量木椅與細柱燈，側邊只放小型植栽模組。
- 右上 AI 學伴設計師後側使用植栽銜接地圖邊緣。
- 中央移動區、左側廣場及四個入口維持淨空。
- 不增加道路或入口地磚。

### 已確認

1. 上緣植栽與圍牆密度依 v1 定案。
2. 樹木高度依 v1 定案。
3. 上方保留兩張座椅。

正式素材已拆成 `props/` 內較小的獨立透明元件：樹木、花台／矮牆、座椅及燈具；不再生成整張透明邊界畫布。後續以這些元件組合正式後景與前景配置。

`boundary-props-scale-preview-v1.webp` 是獨立元件縮放到 `1920 × 1080` 地貌上的比例檢查圖，只供確認清晰度、密度與彼此比例，不是正式場景合成圖。

正式合成時，長椅與細柱燈改用本預覽顯示尺寸的 56.25%（0.75 × 0.75）；樹木與矮牆花台維持原比例。四棟建築合成比例以 `formal-map-four-building-scale-preview-v6.webp` 檢查。

### 生成提示摘要

保持 v5 地圖、四棟建築、人物、廣場及中央留白不變，只以不連續的暖灰矮牆、低花台、中型疏冠樹、少量木椅與細柱燈整理後側和側邊邊界，避免遮住房門與建築核心視覺。

生成方式：Codex 內建影像生成工具（imagegen 技能，整體密度預覽模式）。
