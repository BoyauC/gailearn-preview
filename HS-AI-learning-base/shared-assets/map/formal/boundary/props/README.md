# 地圖邊界獨立素材

狀態：第一組正式候選素材，供後側與側邊景物模組化配置。

## 素材清單

| 檔案 | 內容 | 建議用途 |
|---|---|---|
| `boundary-tree-medium-v1.webp` | 中型疏冠校園樹 | 建築後側、地圖上緣及角落遮景 |
| `boundary-planter-wall-v1.webp` | 弧形暖灰矮牆花台 | 建立不連續邊界、銜接樹木與座椅 |
| `boundary-bench-v1.webp` | 暖木色校園長椅 | 地圖上緣休憩點，正式配置保留兩張 |
| `boundary-lamp-v1.webp` | 細柱型校園燈 | 邊界節奏、入口外圍及夜間擴充預留 |

## 正式配置比例

- 長椅與細柱燈在正式地圖中的顯示尺寸，先縮至 75%，再依確認縮小 25%；最終採 `boundary-props-scale-preview-v1.webp` 所示尺寸的 **56.25%（0.75 × 0.75）**。
- 樹木與矮牆花台維持目前預覽比例。
- 以上是遊戲內顯示比例，不縮小高解析透明母檔；已於 `formal-map-four-building-scale-preview-v6.webp` 進行整體比例檢查。

## 使用規則

- 四張皆為獨立 WebP 真透明素材，不包含棋盤格或整張畫布背景。
- 素材只提供原始高解析版本；接入遊戲時依 `1920 × 1080` 設計座標縮放，不預先破壞性縮小母檔。
- 樹木與高植栽必須依人物腳底 Y 值分配至後景或前景遮擋層。
- 矮牆、花台、長椅及燈具需要各自建立簡化碰撞形狀，不以圖片外接矩形當碰撞範圍。
- 同一物件重複使用時可小幅調整縮放或左右鏡像，但不可造成光線方向互相矛盾。
- 中央移動區、四個房門與左側廣場維持淨空。

## 透明度檢查

- 原始生成 PNG 皆具有 RGBA alpha 通道。
- 已清除低於 96 的背景殘留透明像素，再裁切至有效內容範圍並以無損 WebP 保存。
- 保留物件邊緣、接地陰影與燈光必要的半透明像素。

## 生成方式

使用 Codex 內建影像生成工具（imagegen 技能，`stylized-concept` 類型），逐件生成樹木、矮牆花台、長椅及細柱燈；風格與比例以已確認的 v5 地圖及邊界密度預覽為參考。
