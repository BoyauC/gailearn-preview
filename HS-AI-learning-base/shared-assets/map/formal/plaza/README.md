# 左側廣場獨立素材

## plaza-v1.webp

- 單一透明 WebP 物件，不含草地、道路、入口地磚、人物、房間圖示或介面文字。
- 外觀為低矮暖白／淡沙色圓形平台，中央設置小型藍白 AI 核心，四周保留四個低矮圓形節點。
- 功能定位是一般出生、返回與四房完成狀態的共同集合位置，不代表關卡順序，也不是傳送門。
- 正式地圖顯示尺寸參考 `plaza-map-preview-v1.webp`；實際尺寸由程式依 1920 × 1080 設計座標縮放。
- 廣場獨立於地貌底圖，後續可調整位置而不用重畫草地與沙土。

## plaza-map-preview-v1.webp

- 將 `plaza-v1.webp` 縮放後放在左側地貌上的比例預覽。
- 只供位置與大小檢查，不作正式遊戲合成底圖。

### 生成提示摘要

依 v5 地圖左側廣場概念，重製為獨立透明的低矮圓形平台與藍白 AI 核心；不含道路、關卡符號、文字、人物或周邊植栽。

生成方式：Codex 內建影像生成工具（imagegen 技能，獨立透明物件模式）；另清除低透明背景雜訊並裁切有效邊界。
