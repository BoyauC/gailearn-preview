# 正式地貌圖層

## terrain-base-v1.webp

- 畫布：`1920 × 1080`。
- 格式：不透明 WebP，品質 92。
- 內容：滿版草地、低對比沙土色差及自然磨損；不含建築、人物、廣場設施、入口地磚、道路、植栽、邊界與介面。
- 用途：正式地圖最底層及後續所有透明圖層的共同座標基準。
- 視覺基準：`../../concepts/hs-ai-learning-base-map-character-2x-scale-v5.webp`。

### 本輪確認重點

1. 草地明度及飽和度是否適合作為長時間遊玩的底色。
2. 沙土色差是否足以避免地面單調，又不會被理解成固定道路。
3. 中央地面是否維持足夠安靜，方便人物、腳邊光環及對話框辨識。

### 尚未加入

- 左側廣場。
- 四棟建築入口踏板與道路：已取消，不再製作。
- 後側圍籬、花台、樹木、座椅與燈具。
- 前景樹冠及其他人物遮擋層。
- 建築、人物、光環、陰影及碰撞資料。

除已取消的入口踏板／道路外，其餘項目將以獨立素材或透明分層製作，不畫入 `terrain-base`。

### 生成提示摘要

以 v5 整合地圖為色彩、光線與地面質感參考，移除所有建築、人物、廣場、設施及立體植栽，重建滿版低對比草地與自然沙土色差，不建立道路或指定關卡動線。

生成方式：Codex 內建影像生成工具（imagegen 技能，地貌重建模式）；輸出後統一為 1920 × 1080 WebP。
