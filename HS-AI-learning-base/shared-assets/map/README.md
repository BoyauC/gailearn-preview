# 共用地圖素材

放置高中AI學習基地地貌、四房建築、廣場、入口與碰撞參考素材。

正式地圖分層、單棟建築輸出、人物原點及碰撞資料格式統一依 `FORMAL-MAP-ASSET-SPEC.md` 執行。

## 已確認場景範圍

- 正式地圖必須鋪滿整個遊戲視窗，不得只在畫面中央放置橢圓形綠色土地，外圍留下大片無功能的淺藍背景。
- 草地、沙地、簡潔鋪面及校園設施可延伸到畫面邊緣，再以花台、透明資料牆、座椅或植栽自然界定可行走範圍。
- 滿版是指完整場景構圖，不代表每個畫面邊緣都必須可行走；操作安全區及自然碰撞邊界仍須保留。
- 目前原型建築是 CSS 比例測試形狀，不是正式地圖美術。
- `concepts/hs-ai-learning-base-map-concept-v1.webp` 是第一張滿版地圖美術方向稿，尚待使用者確認建築比例、邊界密度、廣場大小及四房輪廓。

## 碰撞設定狀態

- `prototypes/map-scale-test` 現有碰撞區只服務目前的 CSS 測試房屋，屬暫定技術數值。
- 房屋造型、地圖美術及入口位置尚未確認，因此碰撞矩形、房門觸發點、入口出生點與接近距離均未定案。
- 正式素材確認後須重新量測，不可將原型百分比座標直接複製到正式地圖。

## 已確認人物比例與落腳判定

- 建築與地圖比例採 `concepts/hs-ai-learning-base-map-four-buildings-integration-v4.webp`。
- 正式人物比例採 `concepts/hs-ai-learning-base-map-character-2x-scale-v5.webp`，即人物約為 v4 尺度參考角色的 2 倍；其餘地圖配置不因人物放大而調整。
- 人物腳底使用斜俯視橢圓光環標示落腳中心，移動時持續跟隨角色。
- 程式中的角色位置原點、地面排序點及碰撞偵測基準統一設在雙腳接地中心。
- 玩家實體碰撞採落腳中心周圍的小型圓形／橢圓形範圍，不使用整張人物矩形，避免頭髮、手臂或書包碰到建築時提早停止。
- 房門互動區、建築碰撞區與玩家碰撞圓是三種不同範圍；正式建築定稿後分別量測，不以光環外圈直接代替全部判定。

## 地貌與建築安放原則

- 正式地圖不設四房入口道路或需與建築對齊的入口地磚。
- 四棟建築直接安放在連續草地／沙土地上，日後可微調位置而不用同步重畫地貌。
- 左側廣場維持獨立素材；廣場不是道路起點，也不連接指定關卡路線。
