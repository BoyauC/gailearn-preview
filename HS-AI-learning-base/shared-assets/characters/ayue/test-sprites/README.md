## 四向待機母檔 v1

- 四張皆為 `1024 × 1536` 固定畫布、RGBA WebP，已驗證含真正透明 Alpha。
- 檔名為 `ayue-idle-front-v1.webp`、`ayue-idle-back-v1.webp`、`ayue-idle-left-v1.webp`、`ayue-idle-right-v1.webp`。
- 執行階段預定採「腳底中央」作為角色錨點，避免人物在斜俯視地圖移動時上下跳動。
- 本輪先確認方向辨識、人物比例與透明素材流程；四向人物在畫布中的腳底高度仍有些微差異，正式動畫切格前須統一基準線與顯示縮放。
- 目前人物與書包仍在同一張測試圖。四房裝備不得直接畫死在本體上，正式整合時須另做獨立透明圖層。

## 驗證結果

- 阿岳的黑色短髮、暖琥珀外套、深藍內搭、深色長褲、深藍鞋、四槽書包及高中比例可延續。
- 左右步行必須獨立製作，不使用水平鏡像。
- 羅盤直接生成在四向人物上時，背面曾跑到錯誤肩側，證明裝備必須獨立分層，不可畫死在角色本體。
- 方向表與動作表的棋盤格是烙印背景，檔案沒有Alpha通道，因此只作造型、比例及動作參考，**不是可直接上線的透明精靈圖**。
- 動作表左右兩列的視覺方向與命名須在正式切圖時再次校對；不得直接把整張圖當作sprite sheet載入。
- 多元視野羅盤概念可用於確認裝備輪廓，但仍需依阿岳左肩帶實際尺寸重畫透明分層素材。
