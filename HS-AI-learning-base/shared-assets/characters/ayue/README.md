# 高中AI學習基地｜共用主角阿岳

## 素材定位

本資料夾存放四房共用的高中版玩家主角「阿岳」。第一階段先建立角色基準表，用於確認身分、年齡感、比例、配色、四向外觀、表情方向及模組化書包；尚未拆分為正式地圖走路影格或各房裝備圖層。

## 角色延續

- 以國中CH6事件角色阿岳作為身分與配色參考，重新設計為原創高中青春版。
- 保留黑色短髮、微翹髮束、暖琥珀外套、深藍內搭及親切沉著的辨識特徵。
- 高中版約6～6.5頭身，肩線與四肢較成熟，但仍維持平板地圖縮小後可辨識的遊戲比例。
- 高中版可獨立理解；不要求玩家知道國中版照片事件。

## 第一階段基準

- 四向：正面、左側、背面、斜前方。
- 三表情：觀察好奇、專注推理、放心自信。
- 模組化深藍書包，保留四個空徽章槽。
- 配色：暖琥珀、深藍、炭黑，書包五金使用少量青綠。
- 第一階段不加入已取得徽章、房間專屬裝備、校徽、文字或發光英雄盔甲。

## 四房成長方向

每完成一房：

1. 單房回顧後頒發該房徽章。
2. 徽章加入書包對應槽位。
3. 解鎖一項在地圖縮小後仍可辨識的房間能力裝備。
4. 透過統一進度介面寫入localStorage，返回地圖時更新角色外觀。

四房徽章視覺語言共用外框、尺寸、材質、光影及取得動畫；中央圖形、主題色與能力短句各自不同。

## 後續素材階段

### 第二階段｜地圖精靈

- 依實際地圖視角重畫或整理四向／八向地圖精靈。
- 待機、移動、接近入口、互動、取得徽章及通關動作。
- 平板橫向实际尺寸测试，確認輪廓與裝備辨識度。
- 正式地圖人物與建築比例採 `../../map/concepts/hs-ai-learning-base-map-character-2x-scale-v5.webp` 的校正結果；人物約為 v4 整合概念稿尺度人物的 2 倍。

## 地圖落腳光環與角色原點

- 人物移動時，腳邊顯示符合斜俯視透視的橢圓形光環，作為玩家位置與操作焦點提示。
- 光環位於角色、裝備與前景遮擋圖層下方；不得遮住鞋子或形成大型魔法陣效果。
- 建議使用低飽和青綠／淡青白細環與柔光，維持高中手冊、徽章及基地介面的共用色彩語言。
- 角色座標原點固定在雙腳接地中心，也就是光環中心；切換待機與移動影格時原點不得跳動。
- 光環可以跟隨移動狀態輕微明暗或呼吸，但不得用縮放造成角色看似忽大忽小。
- 光環是視覺提示，不直接等於完整碰撞面積；程式可使用同一中心點建立較小的腳底碰撞圓，人物頭部、書包與手臂不納入地面碰撞。
- 房門接近與互動判定可由此落腳中心計算距離，但觸發半徑須與實體碰撞半徑分開設定。

### 第三階段｜分層裝備

- 阿岳本體、書包、四枚徽章及四房裝備分層輸出。
- 避免為每種徽章組合重畫完整角色，降低四向與動畫組合數。
- 重要通關動畫及對話立繪可另製高品質合成版本。

### 第四階段｜各房整合

- 各房玩法確認後才定稿該房裝備，避免目前尚未規劃的兩房造成返工。
- 四房完成後，書包四槽全亮並出現低調連線，解鎖總回顧與證書；角色仍保持高中校園學習者形象。

## 檔案

- `ayue-hs-character-baseline.webp`：四向、三表情、四槽書包整合的單一WebP角色母檔；專注推理表情已使用修正後的藍筆與握法，各角色、表情與書包之間保留獨立裁切空間。
- `test-sprites/`：第一輪四向、動作及多元視野羅盤測試參考；目前仍含烙印棋盤格，不能直接當透明正式精靈使用，詳細限制見子資料夾README。

## 生成資訊

- 生成方式：Codex內建影像生成工具。
- 參考圖角色：國中CH6阿岳四向與表情動作表。
- 參考圖用途：身分、配色與性格延續；高中版為重新設計，不直接拉伸或冒充原圖正式素材。

## 製作界線

- 本基準表先供視覺確認，不直接作為最終遊戲sprite sheet。
- 尚未確認的兩房不得先用任意圖示填滿徽章槽。
- 正式切圖前應確認四房名稱、徽章及地圖實際角色顯示尺寸。
- 共用資料夾只保留一份正式WebP角色基準表，避免舊表情或分離修正版被誤用。
